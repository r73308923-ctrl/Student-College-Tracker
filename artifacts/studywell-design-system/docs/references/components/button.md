## Extracted behavior

- Four semantic variants: primary, secondary, ghost, and danger.
- Full pill rounding, compact vertical rhythm, bold compact label, and optional
  icon separated by a small gap.
- Disabled state reduces opacity and prevents interaction.

## Design rules

- Use deep teal for the main action and marigold-tinted surfaces for secondary
  actions.
- Reserve coral for destructive actions; never use it as a decorative accent.
- Keep button labels short and action-led.
